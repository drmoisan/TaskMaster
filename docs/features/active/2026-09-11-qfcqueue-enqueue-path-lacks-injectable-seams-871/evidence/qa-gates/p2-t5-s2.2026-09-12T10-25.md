## The three marshalling members, now single-expression forwards

```
        internal Task UiIdleCallAsync(System.Action action) =>
            UiIdleDispatcher.InvokeIdleAsync(action);

        internal Task<T> UiIdleCallAsync<T>(Func<T> func) =>
            UiIdleDispatcher.InvokeIdleAsync<T>(func);

        internal Task<T> UiIdleAsyncCallAsync<T>(Func<Task<T>> func) =>
            UiIdleDispatcher.InvokeIdleAsync<T>(func);
```

Each body is one expression and each is routed through the seam property. The parameter lists and
return types are unchanged from the anchor, so no member was retyped or re-signed. The `async`
modifier is dropped because an expression-bodied forward returns the callee's task directly; the
member signature, which does not include that modifier, is identical.

The explicit type argument on the two generic forwards is load-bearing. Without it, an argument of
type `Func<Task<T>>` is applicable to both generic interface members — once with the type parameter
bound to `Task<T>` and once with it bound to `T` — and neither candidate is better, so the call is
ambiguous. Supplying the type argument leaves exactly one applicable candidate in each case.

## Seam shape

`UiIdleDispatcher` is an internal property over the private backing field `_uiIdleDispatcher`. The
getter is a null-coalescing assignment that constructs `UiThreadIdleDispatcher` on first read, so
constructing a queue still performs no read of the process-wide dispatcher. The setter throws
`ArgumentNullException` on null.

## Adapter placement

`UiThreadIdleDispatcher` is declared `internal sealed` in this file rather than in a file of its own
because the only other suitable folder has a space in its name and a path containing a space is
dropped by the downstream change-footprint tooling.
