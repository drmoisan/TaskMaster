**D2 — Evidence artifacts versus raw tool output.** Every evidence artifact is a Markdown file under
`FEATURE/evidence/<kind>/` carrying `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`,
plus `ExpectedExitCode:` when the expected code is not 0. Raw tool output — MSBuild logs, `.trx`
files, `.coverage` attachments, Cobertura XML — is written under `coverage/plan812/<task-id>/`,
which is git-ignored by `.gitignore:144` (`coverage/*`). Raw output is never committed, because an
MSBuild log carries absolute host paths and a `.trx` carries `runUser` and `computerName`
attributes. Only sanitized counts, exit codes, and numeric coverage values are transcribed into the
committed evidence Markdown. `*.trx` has no `.gitignore` rule of its own, so writing it anywhere

Each task that writes under `coverage/plan812/<task-id>/` creates that directory before invoking its
command, with `pwsh -NoProfile -Command 'New-Item -ItemType Directory -Force -Path coverage/plan812/<task-id> | Out-Null'`

intermediate directories and fails with `MSB1029` when the target directory is absent. Every MSBuild
invocation carrying a `/flp:` switch also carries `/fl` immediately before it, because `/flp` only
configures the file logger and `/fl` attaches it. Every acceptance condition that counts a literal in
one of these logs first records that the log file exists and that its total line count is greater
than zero, because a count taken over a missing file is also zero and would otherwise read as a pass.

code of `dotnet tool run csharpier format .`, which is 0 whether or not it rewrote files.
