## Design (binding decisions, derived from verified context)

1. `StoreWrapperInitClock` — a process-global, thread-safe accumulator in UtilitiesCS, NOT `[ExcludeFromCodeCoverage]`. Internally accumulates microseconds in a `long` via `System.Threading.Interlocked.Add` to keep `Add` lock-free and overflow-safe across concurrent store inits; `TotalMs` reads the current snapshot via `Interlocked.Read` and divides by 1000.0; `Reset()` (for tests) sets the counter to 0 via `Interlocked.Exchange`. Exposed as a static accumulator (process-global) because StoreWrapper instances are created independently and the phase-net read in `ApplicationGlobals` is cross-instance. No clock reads, no COM, no I/O.
2. `[store-wrapper-init]` formatting — a pure formatter co-located with the clock (a separate coverable helper `StoreWrapperInitProbe`, constructor-injected `Action<string>` sink, mirroring `StoreFilterAttribution`). The `Stopwatch` and COM calls stay in `StoreWrapper.Init`; only the formatting is coverable. `Init()` wraps its body with one `Stopwatch`, adds the measured elapsed to `StoreWrapperInitClock`, and emits one `[store-wrapper-init] store=<DisplayName-guarded> totalMs=<F1> threadId=<id>` line in addition to the existing per-COM `[Startup timing]` lines. `Restore` is covered because it calls `Init()` (no separate clock add in `Restore` to avoid double-counting).
3. `[phase-net]` formatting + net computation — added to the existing coverable `StartupDiagnosticsProbe` in TaskMaster (reused per the delegation prompt). The live `StoreWrapperInitClock.TotalMs` read in `ApplicationGlobals` goes behind a NEW `protected internal virtual double SampleStoreWrapperInitTotalMs()` seam (mirrors the `BeginPhaseGcCapture`/`EmitPhaseGcDelta` live-read pattern) so the three test subclasses override it to return a deterministic value without a live clock. Net computation rule: `netMs = grossMs - storeWrapperInitMs`, clamped at `0.0` when `storeWrapperInitMs > grossMs` (a phase whose sampled delta exceeds its own gross wall-clock, possible when a concurrent store init on another thread accumulates into the shared clock during the phase window); the clamp is the defined rule and is unit-tested.
4. Additive only: the existing `[Startup timing]` gross table, `[engine-init]`, `[ui-heartbeat]`, `[gc-delta]`, `[continuation-resume]`, `[startup-lifetime-heartbeat]`, `[store-filter]`, `[spam-init]` lines, `PreserveReferencesHandling.All`, and the model deserialize are untouched.
