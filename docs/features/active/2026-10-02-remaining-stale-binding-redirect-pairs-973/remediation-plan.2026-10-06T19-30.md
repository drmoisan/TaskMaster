## 6. Conventions

- **C1 Artifact fields.** Every command-bearing artifact carries `Timestamp: <yyyy-MM-ddTHH-mm>` read from the clock by CMD-TIMESTAMP as the first command of the task, `Command: <exact invocation>` (with the worktree prefix replaced by `<execution-worktree-root>`), `EXIT_CODE: <int>` as observed, and `Output Summary:` (1 to 20 lines). One artifact carries one `EXIT_CODE:` row; further exit values are named `Output Summary:` lines. An artifact that records an expected non-zero exit carries `ExpectedExitCode:`; none in this plan does.
- **C2 Artifact naming.** `<FEATURE>/evidence/<kind>/<name>.<timestamp>.md` as each task states; the three Phase 3 gate artifacts carry fixed names (`r1-poshqc-format.md`, `r1-poshqc-analyze.md`, `r1-poshqc-test.md`) and a loop iteration that is not the final clean pass writes `<stem>.iter<N>.md`.
- **C3 MCP exit derivation.** For a PoshQC MCP call, `EXIT_CODE:` is 0 when the payload `ok` is true (and, for the test tool, the JUnit root `failures` and `errors` are 0) and 1 otherwise; the payload is recorded verbatim with the worktree root replaced by `<execution-worktree-root>`.
- **C4 Host paths.** No evidence line, and no line of this plan, carries an absolute host path, machine name or account name; `<execution-worktree-root>` is the placeholder for the item worktree's absolute path, which the executor substitutes from its launch prompt and never writes into the feature folder. - **C5 Tool routes (binding Bash discipline).** Read-only tree observations use the Read, Grep and Glob tools or `git`. Every git command is `git -C <execution-worktree-root> ...` as a single Bash command with no `&&`, `;` or `|`. Every shell step is one `pwsh -NoProfile -Command '<payload>'` invocation whose payload is single-quoted so the parent never interpolates `$`, contains no single-quote character (strings inside use double quotes), names every file operand under `<execution-worktree-root>` with forward slashes, and never issues `cd` (Set-Location -LiteralPath where a location is needed). `cd`, `grep`, `sed`, `awk`, `cat`, `head`, `tail`, `find`, `cp`, `mv`, `rm` and `echo` are never issued through the Bash tool. Grep patterns are ripgrep patterns run through the Grep tool; a Grep over a gitignored file passes the absolute file path and no glob. If the Bash tool refuses a pwsh invocation the executor records `PWSH-REFUSED: <tool message>` and STOPs (`LAUNCH-TOPOLOGY: ISOLATED` for the orchestrator to relaunch non-isolated; not a plan defect).

## 7. Command definitions

Substitution tokens: `WORKTREE` = `<execution-worktree-root>`; `FEATURE` = `docs/features/active/2026-10-02-remaining-stale-binding-redirect-pairs-973`; `BRANCH` = `bug/remaining-stale-binding-redirect-pairs-973`; `CYCLE-BASE` = `d873200e87df1e8e79c2fec18a758cdf8150b134`; `PROJECT` = `TaskMaster` or `UtilitiesCS`.

**CMD-TIMESTAMP** — `pwsh -NoProfile -Command 'Get-Date -Format yyyy-MM-ddTHH-mm'`; prints one line in the form `yyyy-MM-ddTHH-mm`.
