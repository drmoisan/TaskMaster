## Execution conventions

- Shell discipline: no `cd`. Commands run as a single `pwsh -NoProfile -Command "Set-Location -LiteralPath '<worktree root>'; ..."` invocation, or as `git -C <worktree root> ...`. Scripts are invoked by an absolute path built at run time with `Join-Path (Get-Location).Path`, because a relative `-File` path resolves against the caller's directory. `<worktree root>` is the absolute path of the item-941 worktree.
- Artifact contract (ARTIFACT-CHECK): an evidence artifact is a Markdown file whose text contains one line each beginning `Timestamp:` (format `yyyy-MM-ddTHH-mm`), `Command:`, `EXIT_CODE:` and `Output Summary:`. A task that names ARTIFACT-CHECK is complete only when the file exists and a `git grep --no-index -c -F` search of each of those four tokens returns at least 1. A tool-driven check with no native exit code is run as a `pwsh` payload that exits 0 only when every stated condition holds, and its exit code is the recorded `EXIT_CODE:`.

### Target test source (inserted after the blank line 88 and before the `[TestMethod]` at line 89)

The block is 24 lines (23 code lines plus one trailing blank line). Every line is at most 100 columns so it is CSharpier-stable.

```csharp
        /// <summary>
        /// A value-producing dispatch on an owner-only dispatcher (null context) outside any
        /// executing Dispatch callback must fault even when the caller is the owner thread.
        /// </summary>
        [TestMethod]
        public void DispatchValue_OwnerOnlyOnOwnerThread_FaultsOutsideExecutingCallback()
        {
            // Arrange
            var errors = new List<Exception>();
            BreadcrumbUiDispatcher dispatcher = CreateOwnerOnlyDispatcher(errors.Add);
            int executions = 0;

            // Act
            Task<int> result = dispatcher.DispatchValue(() => executions++);

            // Assert
            result.IsFaulted.Should().BeTrue("the null-context fault is synchronous");
            Exception fault = result.Exception.InnerException;
            fault.Should().BeOfType<InvalidOperationException>();
            fault.Message.Should().Contain("outside an executing Dispatch callback");
            executions.Should().Be(0);
            errors.Should().ContainSingle().Which.Should().BeSameAs(fault);
        }

```

Design notes: no await sits between constructing the dispatcher and calling `DispatchValue`, so both run on the same (owner) thread; `DispatchValue` returns `Task.FromException<int>` synchronously on the null-context path (lines 180-188), so no wait, sleep or delay is needed; the sink receives the same exception instance because `reportFailure` defaults to true (lines 185-186). Node ID: `QuickFiler.Test.Viewers.BreadcrumbPopupBoundaryCoverageTests.DispatchValue_OwnerOnlyOnOwnerThread_FaultsOutsideExecutingCallback`. Before the fix the message contains `cannot marshal cross-thread UI work`, so the `Contain` assertion fails; the FluentAssertions `Contain` failure text contains `to contain` (recorded in the #900 evidence).
