## The defect and the invariant

`WireIntentEvents()` (`QuickFiler/Controllers/QfcItemController.EventWiring.cs:66`) performs 17 subscriptions; `UnwireIntentEvents()` (`:446`) performs 16 detachments. The 17th subscription, added by this feature at `:94`, is `_itemViewer.PicturesChanged += this.CbxPictures_CheckedChanged;` and has no matching detachment. The invariant to restore is: **every event `WireIntentEvents()` subscribes is detached by `UnwireIntentEvents()`; after `Cleanup()`, a controller holds zero live subscriptions on its viewer.** The remedy is one production line — the executor will create the exact literal `_itemViewer.PicturesChanged -= this.CbxPictures_CheckedChanged;` — plus a RED-first regression test, a spec/handoff-record reconciliation, and a full toolchain refresh.
