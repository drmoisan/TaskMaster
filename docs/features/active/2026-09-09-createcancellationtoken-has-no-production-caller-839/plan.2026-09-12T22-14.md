## Objective and decided remedy

`QfcHomeController.CreateCancellationToken()` has no production caller. The synchronous initialisation path (public constructor, then `Init()`, then `Run()`) therefore hands `default(CancellationToken)` to the datamodel loader and the queue loader, and a null `CancellationTokenSource` to the form-controller loader, so `QfcFormController.LoadItems` returns early on its null-source guard and nothing loads, with no log line and no exception. The path is latent: `RibbonController.LoadQuickFiler()` is its only production caller and that method has zero callers repository-wide (re-derived in this pass: one hit for the word-bounded regex LoadQuickFiler outside docs/, the declaration itself). No task in this plan may describe the defect as user-visible.

Remedy (a), decided by the orchestrator and not re-litigated here: insert the single statement `CreateCancellationToken();` as the first statement of `QfcHomeController.Init()`, immediately after the opening brace and before the `QfcDataModelLoader` call. Remedies (b) non-nullable field, (c) guard removal, (d) dead-path deletion and (e) consumer fail-fast are rejected or deferred per spec.md "Rejected alternatives" and are not adopted by any task.

Exactly one production member changes: `Init()` gains one statement. None of the 25 construction sites of `QfcHomeController` changes.

Its documented reason for the deduplication is that Cobertura repeats a source line in the method-level view and again in the class-level rollup, so a descendant-axis count counts the line twice (the helper cites issue 441); its documented reason for reading both views rather than one is that a class element with no lines element, no methods element, or neither is valid input, so a single-axis enumeration can report a covered line as absent and would make the AC11 LINE88_HITS gate fail on a correct fix. Maximum hits per line number is retained, as the helper does.

            CancellationToken dataModelToken = default;
            CancellationToken queueToken = default;

                dataModelToken = token;
                return mockData.Object;
            };
