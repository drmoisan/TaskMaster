## Planner decisions recorded (spec open questions and constraints)

- **Drive-rooted input (spec open question, AC1).** `IsFullOutlookPath` returns `true` for drive-rooted input: values that are `\\`-rooted, values leading with a single `\` or `/`, and values whose second character is `:` (e.g. `C:\...`). Rationale: a drive-rooted value can never be a valid archive-relative stem, no legitimate stem contains a volume separator in position 1, and rejecting it costs nothing while providing defence in depth against any future producer that leaks a filesystem path. This decision is restated in the XML doc of `IsFullOutlookPath` (AC1 requires the decision recorded with rationale).
- **`ask` parameter (AC12).** The never-read `bool ask = true` parameter of `FolderConverter.ToFsFolderpath` is REMOVED (not `[Obsolete]`). Precondition task P5-T5 verifies by search that no call site passes it explicitly before removal.
