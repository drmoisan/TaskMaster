## Test Conventions (binding on every test-case task)

- MSTest 4.3.3 (`[TestClass]` / `[TestMethod]`), Moq 4.20.72, FluentAssertions 8.10.0,
  Arrange–Act–Assert, descriptive names, clear failure messages.
- Outlook Interop types (`MailItem`, `Folder`, `MAPIFolder`, `Store`, `Items`, `Application`,
  `NameSpace`, `Conversation`) are mocked **directly with Moq**, enabled by
  `<EmbedInteropTypes>False</EmbedInteropTypes>` at `QuickFiler.Test.csproj:270-272` and `:318-320`.
  No new adapter interface is introduced.
- Headless viewer construction uses `FormatterServices.GetUninitializedObject` with
  `GC.SuppressFinalize` on the instance (precedent
  `QuickFiler.Test/Helper Classes/QfcThemeHelperTests.cs:331-335`,
  `ViewerQueueStaticWrapperTests.cs:330-334`).
- `SystemColors` reads are machine-theme dependent: assert symbolically
  (`.Should().Be(SystemColors.Control)`), never against a literal ARGB value.
- Never call `ThemeControlGroup.ApplyTheme(bool async)`, `Theme.SetTheme(bool async)`,
  `Theme.SetMailRead(bool async)`, or `Theme.SetMailUnread(bool async)` — all route through
  `UiThread.Dispatcher` or `Control.Invoke`. Use the parameterless overloads only.
- **The clock abstraction in this repository is `System.TimeProvider` with
  `Microsoft.Extensions.Time.Testing.FakeTimeProvider`.** The research established that NO F4
  production file has any time dependence and NO banned API, so **no clock seam is planned and none
  may be added**.
- `Thread.Sleep`, `Task.Delay`, `SpinWait.SpinUntil` with a wall-clock budget, `DateTime.Now`,
  `DateTime.UtcNow`, `Random.Shared`, and any real wall-clock wait are **prohibited** in new tests
  (repo-root `BannedSymbols.txt`; `.claude/rules/general-unit-test.md` § Determinism Infrastructure).
- No temporary files, no external services, no live `Form`, no popups, no UI-thread dependence.
- New test files adopt the namespace of the existing test file that sits beside them for the same
  production type. The three existing namespaces in `QuickFiler.Test/Helper Classes/`
  (`QuickFiler.Test.HelperClasses`, `QuickFiler.Helper_Classes.Tests`, `Z.Unfinished.QuickFiler.Test`)
  are NOT normalised by F4.
- Every test class touching `ItemViewerQueue` or `EfcViewerQueue` carries `[DoNotParallelize]` plus
  both `[TestInitialize]` and `[TestCleanup]` calling that wrapper's `ResetForTesting()`.
