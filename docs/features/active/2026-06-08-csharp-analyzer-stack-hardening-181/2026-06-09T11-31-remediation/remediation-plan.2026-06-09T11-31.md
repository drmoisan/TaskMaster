## Objective

Convert EVERY prohibited non-deterministic timing primitive (`Thread.Sleep`, `ManualResetEventSlim.Wait(<timeout>)` / `signal.Wait(<timeout>)`, `SpinWait.SpinUntil(..., <timeout>)`, and equivalent wall-clock waits) cataloged in the research inventory (24 occurrences, groups A–L) into deterministic equivalents, using behavior-preserving production seams S1–S6 and the test-only fixes the research classifies. Fix the named failing test `Serialize_WithConfiguredPath_TriggersDeferredThreadSafeWrite` FIRST (S1 / Phase 1). No new NuGet packages; reuse existing `ITimerWrapper`/`IGenericTimer`; add a single `ManualFireTimerWrapper` helper inside the test project.

- No `.editorconfig` / `.globalconfig` / vendored / `BannedSymbols.txt` / analyzer-wiring / `.claude/rules` changes. Keep the flat artifact layout; do not reorganize committed artifacts.
- MSTest + Moq + FluentAssertions only. No temp files. No external dependencies in tests.
