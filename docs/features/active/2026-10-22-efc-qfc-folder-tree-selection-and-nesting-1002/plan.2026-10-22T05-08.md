- Every command-step artifact carries `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`; an artifact that records an expected non-zero gate carries `ExpectedExitCode:`. - Every new C# file carries `#nullable enable` and an explicit `<Compile Include>` in its legacy project file.
