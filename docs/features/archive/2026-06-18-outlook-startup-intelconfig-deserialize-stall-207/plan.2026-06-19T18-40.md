**Scope lock:** Exactly three files may change — production `TaskMaster/AppGlobals/AppEvents.cs`, production `UtilitiesCS/EmailIntelligence/IntelligenceConfig.cs`, and test `UtilitiesCS.Test/EmailIntelligence/IntelligenceConfig_Tests.cs`. Do NOT modify `ApplicationGlobals.cs`, `SmartSerializableLoader`, `StartupTimingRecorder`, `PrettyPrinters`, or any other file. If the instrumentation cannot be done within these three files (for example, the 500-line file cap is exceeded), STOP and report rather than widening scope. A small cohesive private helper inside the affected production file is the only permitted structural variation, and any new sibling file must be reported before creation.

**Deliverable intent:** Diagnostic instrumentation only (increment 2). This plan adds (1) per-operation `Stopwatch` timing of the three synchronous COM operations inside `AppEvents.Hook()`, emitted as one consolidated readable log block via the existing log4net logger, and (2) `Stopwatch` timing of `IntelligenceConfig.GetSerializedConfigurations()` so the read-versus-deserialize split is visible in the emitted `[IntelConfig timing]` breakdown. It does NOT change `Hook()`'s subscription behavior or ordering, does NOT change `Config` contents/semantics, and does NOT implement the corrective threading/loading fix (deferred to a follow-up issue after the increment-2 evidence localizes the blocking call).

**Increment-1 preservation rule:** The increment-1 per-resource `DeserializeLoaderAsync` timing (committed `2bc71fd5`) MUST remain intact. The `ResourceTimingRow` `readonly struct`, the per-entry deserialize Stopwatch, `FormatResourceTimingBreakdown`, and the `LastResourceTimingBreakdown` observability property are extended, not replaced.

**Guardrail: net48 type constraints.** Target framework is net48. Do NOT introduce positional `record struct` (its compiler-generated `init` accessors require `System.Runtime.CompilerServices.IsExternalInit`, unavailable on this target → CS0518). Follow the existing increment-1 pattern: a plain `readonly struct` with an explicit constructor (see `ResourceTimingRow` at `IntelligenceConfig.cs:152`). Reuse `FormatResourceTimingBreakdown` / `PrettyPrinters.ToFormattedText` for rendering style consistency.

**Guardrail: banned APIs (BannedApiAnalyzers RS0030).** No `DateTime.Now`, `DateTime.UtcNow`, `Random.Shared`, `Thread.Sleep`, or `Task.Delay`. All timing uses `System.Diagnostics.Stopwatch` (already imported in both production files).

**Guardrail: file-size cap.** No production/test file may exceed 500 lines. Pre-change line counts (verified at planning time): `AppEvents.cs` = 422, `IntelligenceConfig.cs` = 276, `IntelligenceConfig_Tests.cs` = 442. The planned additions are estimated to keep each file under 500. P1 includes an explicit post-edit line-count gate; if exceeded, STOP and report before any extraction.

**Guardrail: COM/VSTO coverage exemption (UT5 explicit-exception call-out).** `AppEvents.Hook()` depends directly on `Microsoft.Office.Interop.Outlook` (`Globals.Ol.ToDoFolder.Items`, `Globals.Ol.OlReminders`, `Globals.Ol.Inboxes`) with no injectable seam, and is in the documented COM/VSTO coverage-exempt set in `CLAUDE.md`. Its instrumentation is logging-only and is verified by inspection rather than a unit test. No live-Outlook test is introduced. This is the explicit exception required by General Unit Test Policy UT5. The `IntelligenceConfig` read-versus-deserialize seam IS unit-testable via `TestableIntelligenceConfig` and is covered by deterministic MSTest.

**Fail-closed evidence rule:** Phase 0 baseline artifacts and Phase 2 final-QC artifacts are mandatory. If any required baseline artifact, final-QC artifact, or coverage-comparison artifact is missing or has incomplete fields, the audit verdict must be BLOCKED or INCOMPLETE, never PASS.

**Evidence accounting rule:** Each evidence-producing task names its exact canonical artifact path. Do not mark an evidence-backed task complete without the artifact on disk containing `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`.

**Canonical evidence root:** `docs/features/active/2026-06-18-outlook-startup-intelconfig-deserialize-stall-207/evidence/`.
