# Issue #609 Remediation Plan

## Objective

Correct the upstream Efc startup-suggestion representation only when a deterministic
`FolderPredictor.FolderArray` regression proves that a persisted full Outlook archive
path reaches the row generator. The generated in-root suggestion must be
`Clients\\North`, and the corresponding projected `FolderScore.FolderPath` must have
the identical value. The router and filing configuration remain compatibility checks,
not remediation targets.
