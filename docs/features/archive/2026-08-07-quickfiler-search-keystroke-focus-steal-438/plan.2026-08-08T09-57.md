## Environment Warnings (binding on every task)

1. `msbuild`, `vstest.console.exe`, and the repo-local `dotnet` are NOT resolvable from the Bash shell, and the Bash tool returns exit code 0 on `command not found` — a skipped build can masquerade as a passing one. Every toolchain invocation MUST go through `pwsh -NoProfile -Command "..."` and MUST end with `; exit $LASTEXITCODE`. When launching pwsh from a bash shell, single-quote the command string so bash does not expand `$LASTEXITCODE`, and prefix `MSYS_NO_PATHCONV=1`.
2. CSharpier MUST be the repo-pinned **1.2.6** via `./.dotnet-sdk/dotnet.exe tool run csharpier`. A global csharpier 1.3.0 is on PATH and MUST NOT be used; version drift produces spurious format diffs against CI. csharpier 1.2.6 requires the `format` / `check` subcommands (see Decisions Record D1).
3. Test-assembly discovery MUST exclude any path containing `\.claude\` so stale agent-worktree builds are not collected. The full-suite coverage runs assert this explicitly.
4. Toolchain order is format → analyzers → nullable → test. If any step fails or auto-fixes files, restart from format.
