When directing a bounded preflight loop, ask for these two whole-plan sweeps BY NAME. Both are
mechanical, both found real defects late on issue #488 (2026-08-25), and neither is found by the
usual "can this acceptance condition fail?" reading.

**1. Ordering integrity.** No task's acceptance may depend on an artifact that a LATER task writes.
Round 4 found two: `[P9-T2]` checked off a criterion citing an index `[P9-T14]` wrote twelve tasks
later, and `[P5-T6]` required a GitHub issue number that `[P7-T5]` opened two phases on. Both were
unsatisfiable in plan order while reading as perfectly reasonable prose. The `[P9-T2]`/`[P9-T14]`
repair was a task-BODY SWAP rather than a renumber — renumbering would have shifted three sibling
tasks and forced edits in four others, so swapping bodies fixed the order at zero cross-reference
churn. Prefer that move.

**2. Citation arity.** If the plan carries a decision rule of the "each check-off cites exactly one
artifact" shape, sweep every check-off against it. On #488 one task cited a second artifact, and the
second artifact was also the WRONG evidence — a line count, which cannot establish the byte-identity
its criterion asserted.

**Why:** these two classes are generated by a plan's own internal rules rather than by any claim about
the repository, so a round sweeping for false facts about the tree will not surface them. They
appeared only once a round ran a systematic per-criterion evidence-before-check-off sweep across all
54 acceptance criteria — which is itself the sweep to ask for, since it is what exposed the whole
conjunctive-criterion class (a criterion conjoining facts produced by different command steps has a
conjunct no single artifact carries).

**How to apply:** put both sweeps in the round-2 or round-3 delegation prompt, not the last round —
they generate structural edits, and a structural edit made in the final round is unvalidated by any
subsequent round. Expect the round that first runs the full per-criterion sweep to report a HIGHER
count than the round before it; see [[preflight-defect-trend-scope-confound]].
