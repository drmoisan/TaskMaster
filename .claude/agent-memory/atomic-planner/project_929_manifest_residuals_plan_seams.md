Seams re-derived while authoring and revising the issue #929 plan (2026-09-28, worktree agent-a74dcedbc13b789fd; round 0 at f0e9b4c53, round 1 revision at c417c249a).

**Why:** each one either made a caller-supplied assumption false or would have produced an unsatisfiable acceptance clause; the round-1 preflight returned 16 defects, most of them in this list.

**How to apply:** re-check before planning any change in scripts/dependencies, any binding-redirect fix, any GitHub-App workflow input change, any plan whose AC demands a cold-restore rebuild, and any plan that anchors a footprint diff on the merge-base of a branch that already carries a promotion commit.

1. **The "import whose package is absent from the manifest" rule already exists.** `Find-PackageAbsentFromManifest` (ConsistencyVerifier.psm1:215-250) covers Import because `$script:FolderBearingKind` (AnalyzerItemRepair.psm1:70) lists it, and ConsistencyVerifier.Tests.ps1:272-290 already asserts 2 findings on an in-memory altcover fixture. The genuine fail-before regression test is a tree-reading Pester file (precedent: DependabotConfig.Tests.ps1 reads .github/dependabot.yml and the workflow via $PSScriptRoot).
2. **Line counts: state the measuring expression.** ConsistencyVerifier.psm1 is 499 lines by `git grep -c ""` and by `@(Get-Content).Count`; the Read tool renders a 500th empty line after the final newline, and the round-0 plan wrote "exactly 500" from that rendering. ConsistencyVerifier.Tests.ps1 is 312 the same way, not 313. State the expression (`@(Get-Content -LiteralPath ...).Count`) next to every count so the executor's figure is comparable.
3. **Repair-PackageManifestConsistency.ps1 cannot fix pre-existing redirect drift.** Line 425 skips the redirect pass unless `$upgrade.Applied` is non-empty, and line 177 skips a candidate equal to the current version. Hand-edit, and use `Invoke-BindingRedirectReconciliation` (ProjectConsistency.psm1:271-375, pure over text) as the read-only pre/post observation: Repair count 1 before, 0 after, ExaminedCount 4.
4. **Cold-restore rebuild is red on the current tree for a cause outside #929.** All 16 analyzer-bearing csproj name `Meziantou.Analyzer.3.0.235` in `<Analyzer Include>` while every packages.config pins 3.0.290. Census: 162 `Analyzer Include=` lines across 17 csproj. Plan a Phase 0 resolvability census + `nuget install` back-fill BEFORE the first /t:Rebuild, declare `ANALYZER-ITEM-STATE:` and a `PRE-EXISTING-OUT-OF-SCOPE-DEFECT:` line, and prove non-repair with a footprint count of zero other csproj/manifests. The repo bundles no nuget CLI: record `(Get-Command nuget).Source` and stop with a report when empty. The orchestrator amended AC7 to permit exactly this recorded back-fill.
5. **Fizzler redirects are stale in 12 of 13 app.config files INCLUDING SVGControl** (UtilitiesCS alone names 1.3.1.0); only SVGControl and UtilitiesCS carry a Fizzler `<Reference>`, so the out-of-scope residual is the 11 others, not 12. Already recorded in docs/features/potential/2026-08-04-stale-fizzler-and-unsafe-binding-redirects.md (Draft).
6. **A promotion commit sits on the branch before execution starts.** `git diff --name-only <merge-base>` therefore already lists docs/features/potential/promoted/<record>.md, which is outside every Write Set, so a footprint gate anchored at the merge-base cannot pass. Record `git rev-parse HEAD` at P0-T1 as `<P0-START>` and anchor the footprint diff there; keep per-file numstat gates on the merge-base only for files the promotion commit did not touch.
7. **Never route a solution Rebuild through scripts/vscode/Invoke-VSBuild.ps1 in a plan with a frozen Write Set:** lines 250-253 run Sync-PackageReferences.ps1 first, which rewrites csproj HintPaths. Use the literal CLAUDE.md msbuild commands with `/flp:LogFile=coverage\...`.
8. **`\"` inside the inner double-quoted string of a `pwsh -NoProfile -Command '...'` one-liner is not an escape.** Double it: `"Analyzer Include=""([^""]+)"""`. Sweep every plan with `[^\\]\\"` before handoff.
9. **A doubled backslash in a plan-authored regex is de-doubled between Bash and pwsh.exe,** so `"[A-Za-z]:\\"` arrives as a pattern that cannot match a drive path and a HITS=0 gate passes vacuously. Build the pattern from `[regex]::Escape([string][char]92)` and add a `SELFTEST=` line that matches a synthetic `Q:\x` string (must print 1).
10. **`[System.IO.File]::ReadAllText("relative")` resolves against the process directory, which Set-Location does not change.** Wrap with `Join-Path (Get-Location).Path`.
11. **`Get-ChildItem -Path <file> -Include *.md` drops a file passed directly.** Filter with `Where-Object { $ext -contains $_.Extension }`. Exclude lines carrying an https URL from the account-name pattern.
12. **MCP `run_poshqc_analyze` and a direct `Invoke-ScriptAnalyzer` apply different rule settings;** never assert their counts equal. Record both, record the difference as `ANALYZE-ROUTE-DELTA:`, and gate the post-change run as at-most-baseline per route.
13. **A sub-agent executor has no dispatch tool.** Every "Hand off to <engineer>" task needs an inline fallback clause with a `WORKER:` substitution line, or preflight rejects it as unperformable.
14. **A "keep the formatter rewrite" branch in the final-QC format step must commit the rewrite** (explicit pathspec, style(929) message) before the loop restarts, or the later porcelain and footprint gates cannot pass.
15. **Every commit task needs a hygiene scan whose folder list covers every path that commit stages,** including the Write Set docs (workflow, README, runbook, psm1, tests), not only the evidence folder.
16. **A GitHub-App secret rename needs maintainer credential action; keeping the name and changing the stored VALUE does not.** Pass `secrets.DEPENDABOT_REPAIR_APP_ID` as `client-id`; the runbook's Part B heading (line 99 "Record the App ID ...") is a sibling that contradicts the AC and must be retitled with the step text.
17. **Sibling stale comments:** ConsistencyVerifier.Tests.ps1:57-59 also carries a "Tracked separately" sentence beside the stale "lines 8 and 514" citation; a comment edit that names only line 57 leaves 59 stale.
18. **actionlint locally:** scripts/dev-tools/run-actionlint.ps1 runs actionlint-bin/actionlint.exe repo-wide (throws if absent), CI pins 1.7.7 (_actionlint.yml:26). Success prints nothing; record `-version` output as the proof the binary ran.
19. **Coverage-floor conflict (CLAUDE.md 80 / rules 85) is tracked as open issue 668.** Gate on CLAUDE.md, record `MEETS-85:` true/false as an observation at each coverage point, cite 668 in a convention so preflight does not raise "policy conflict not acknowledged".
20. **A CI claim ("CI stays green only through its package cache") must be stated as an inference** with the restore-keys lines cited (_build-analyzers.yml / _build-nullable.yml 57-58), never as verified.
21. **A post-commit capture cannot live inside an artifact that is part of the same commit.** Transcribe the head SHA, git show listing and porcelain into the NEXT task's artifact.

Round 2 preflight (six defects, three wording notes; revision applied at HEAD 62448256a):

22. **In a PowerShell array literal the comma binds tighter than `+`.** `@("a" + $x, "b")` yields THREE elements (`"a"`, `$x`, `"b"`), so a pattern array built by concatenation must parenthesise every element: `@(("a" + $x), ("b"))`. Print `PATTERNS=` + `$pattern.Count` and gate it, because an unparenthesised boundary fragment such as `(^|[^A-Za-z0-9])` matches every line and a HITS=0 gate becomes unreachable while SELFTEST still passes.
23. **A bare `[A-Za-z]:\\` drive-letter pattern matches regex text.** `client-id:\s*` contains `d:\s`. Guard the letter with `(^|[^A-Za-z0-9_-])` and add a `SELFTEST_NEG=` line over a synthetic `client-id:\s` string that must print 0. Print hit locations with `[System.IO.Path]::GetRelativePath($root, $_.Path)`, never `$_.Path`, or the listing itself leaks the host path.
24. **Every hygiene consumer needs a remedy clause and a "did not author" stop branch:** fix + re-run in plan-authored files (record `PRE-FIX-HITS:`), stop with a report for issue.md and the plan file (check-offs only). Tool lines that print absolute paths (`Using vstest.console: `, `Coverage projection: `, `Using MSBuild: `, `-WhatIf` targets, every `dotnet --list-sdks` line) must be named in the hygiene convention with their placeholder.
25. **Phase 2 restart rule must say "rewrites a Write Set member", not "a tracked file":** the format step reverts out-of-Write-Set drift by design, so the tracked-file wording makes every iteration restart. State the read-only `csharpier check` explicitly as unable to rewrite and make its P2 gate baseline-relative (`CSHARPIER-FINDINGS:` equal to P0's list) since no C# file is in the Write Set.
26. **Analyzer tuple comparison must drop line numbers for files the plan edits above later findings** (the test file gains It blocks): compare (rule, severity) multisets per edited file, exact tuples elsewhere, and 0 findings for the created file.
27. **Repair-PackageManifestConsistency.ps1 verifies the in-memory repaired text** (lines 411-422: `Get-ProjectVerification -ProjectText $repaired.Text`), so a `-WhatIf` run's `VersionDisagreementCount` may be 0 even with skewed analyzer items on disk. Record DISAGREE with no expectation.
28. **`dotnet --list-sdks` prints `<version> [<sdk-dir>]`,** so "a line ending in `.dotnet-sdk\sdk`" can never match; assert the bracketed path's last segments instead.
29. **The plan body must not contain the literal preflight signal strings** (automation scans plan text for them). End the internal-review record at `UNRESOLVED-GAPS: NONE` and say in prose that clearance lives in the orchestrator checkpoint.
