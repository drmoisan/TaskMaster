Seams met while applying the preflight round-3 deltas to the issue #973 plan (revision 1.3 to 1.4, 2026-10-03). Worktree `.claude/worktrees/agent-a24d410b914bcefd7`.

**Why:** each is a place where the round-3 text was unsatisfiable or let a real difference through.

**How to apply:** when a plan moves code between files, gates a census by text, records commit trailers, counts diagnostics in a build log, or hashes CRLF files.

1. **A declaration census is a multiset, not a set.** `CategoryClassifierGroup.cs` has two `LoadClassifierGroup(` overloads whose declaration lines (195 and 224) are byte-identical, so "every before line appears exactly once in the after lists" was false before any edit. Compare occurrence counts per distinct trimmed text and record `MEMBER-DISTINCT-BEFORE/AFTER` and `MEMBER-DUPLICATE: <text> xN`. Grep the census pattern and look for repeated texts before writing a set-equality clause.
2. **Formatter-owned blank lines adjacent to a moved block are a spec matter.** Removing the two blank lines before the moved `#region` is forced by CSharpier, but AC16/AC23 said "no other removed line". The fix was a spec Planner Amendment under an orchestrator ruling, with repo-wide evidence measured by multiline Grep over `*.cs`: `#endregion[^\n]*\n[ \t]*\}` (194), the blank-then-brace form (1, a Designer.cs), `\{\r?\n[ \t]*\r?\n[ \t]*#region` (0). The zeros are the load-bearing figures; a count that depends on the pattern (class-brace-then-region, 77 by one pattern vs the orchestrator's 81) must not be gated.
3. **The attribution instruction may supply only Co-Authored-By.** Plans that hard-code two trailer `-m` segments must say the second is omitted when no Claude-Session line is supplied and record `TRAILER-2: none (not supplied by the executing session's instruction)`. Sweep every "two trailer" phrase (D8 opening, each commit task's parenthetical, the loop-fix rule, the fallback commit, the completion-report sentence).
4. **Bound diagnostic codes with `\b` on both sides and group alternations.** `"CS0246|CS0103|..."` in `[regex]::Matches` and in a Grep gate matches `CS01030`; write `"\bCS(0246|0103|0104|0234|1061)\b"`. Inside a single-quoted pwsh payload the double-quoted PowerShell string passes `\b` through unchanged (as it already did for `\d`). Sweep single tokens (`CS0121`, `CS0433`, `MSB3277`) the same way; a Grep that counts a code in a csproj comment is a different thing and stays.
5. **`git hash-object` honours `* text=auto`.** Without `--no-filters` CRLF is normalised to LF before hashing, so a formatter that strips CRLF leaves the hash unchanged and the before/after identity gate passes. Use `hash-object --no-filters -- <paths>` for every rewrite observation; check whether any literal expected hash is recorded (here none; every gate was before/after by the same command).
6. **A conditional restore branch cascades.** Restoring one deleted `using` on the P4-T5 repair branch changes the original file's numstat (`1<TAB>97`), the census (`REMOVED-LINES`, `REMOVED-USING-LINES` one lower), and for a file whose only change was that directive it leaves the `.cs` name list and the N-of-N positive control one shorter. Name each adjusted expectation (`RESTORE-ADJUSTED <path>`) in the footprint task and admit the adjusted list in every check-off task that says "exactly the six".
7. **Name the key after what the evidence proves.** `CHANGED-PRODUCTION-LINES: 0` was false (production lines were deleted); the justification proved only that no sequence point was added or removed, so the key is `CHANGED-EXECUTABLE-LINES: 0 (no sequence point added or removed)`.
8. **The self-review enumeration self-hits like a log entry does.** Writing "`two trailer` count 0" into section 14 makes the count 1. Describe superseded literals in prose (the word two before the word trailer) and re-run the sweep after writing the enumeration.
9. **Bash can be disabled outright.** This session had no Bash tool at all (not just a refusal of pwsh), so "do not stage" is provable only by construction (no `git add` issued); say so in the handoff rather than claiming a porcelain observation.
