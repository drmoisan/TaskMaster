Seams the round-1 executor preflight found in the issue #973 plan (15 stale redirect pairs, ADAL deletion, aliased System.Linq.AsyncEnumerable install), worktree `.claude/worktrees/agent-a24d410b914bcefd7`, 2026-10-03. Thirteen defects, all in acceptance wording; none in task structure.

**Why:** each one is a gate that read precisely but could not be satisfied, or could be satisfied for the wrong reason, in the state the executor would actually be in.

**How to apply:** whenever a plan sweeps values across many files, asserts a Pester failure message, adds a host-path residual gate, or hard-codes attribution trailers.

1. **Post-sweep file list = stale list UNION already-corrected list.** Ten configs already carried `Azure.Core 1.63.0.0`, five carried `Microsoft.Bcl.Memory 10.0.0.12`, two carried every `8.23.0.0` IdentityModel name (UtilitiesCS and UtilitiesCS.Test, which were never in the stale lists). "Corrected-version count equals the stale file list" was therefore false before the first edit. Run CMD-PAIR-COUNT with the CORRECTED version in Phase 0 too, record it as `CURRENT <name>=<files>`, gate disjointness from the stale list, and expect the union afterwards. Pin the measured union sizes in the plan (16/15/13/9/15 here) rather than leaving the executor to derive them.
2. **`Should -BeExactly` on two strings does not print `, but got`.** Pester 5 routes string operands to the compare-string message: `Expected strings to be the same, because <Because>, but they were different.` followed by length lines and `Expected: '...'` / `But was: '...'`. A plan sentence "every failure message contains `, but got `" is wrong for every string assertion; key the expectation to the `-Because` text and `But was:`, and keep the `-Because` literal identical in the test code block and every artifact clause (three places here).
3. **A host-path gate that Greps the plan self-hits on its own pattern.** `[A-Za-z]:[\\/]+Users[\\/]|/c/Users/` quoted in P4-T12 made the `/c/Users/` alternative match the plan line that carries it. Write the alternative as `/c/Users[\\/]` (same matches; the quotation ends in `[`, so it cannot match itself) and say why in the task. Measure the folder before execution (0 here) so a later hit is provably executor-written.
4. **Commit trailers are session facts, not plan facts.** The reviewer's session attribution read `Claude Opus 5.5`; the planner's read `Claude Fable 5.1`. Any model name hard-coded in a commit command is wrong for one of them. Write `-m "<Co-Authored-By line from the executing session's attribution instruction>" -m "<Claude-Session line from the same instruction>"`, require the two lines verbatim in the commit artifact (`TRAILER-1:`/`TRAILER-2:`), and state the pre-implementation hook's character rule from `enforce-orchestration-preimplementation-gate-helpers.ps1` lines 30-36 (`$` and backtick unresolvable in every quote state; `<` `>` only outside quotes, so a double-quoted trailer is fine).
5. **No absolute worktree line at all, not even "kept only in this one line as the placeholder's definition".** The shared no-host-path rule admits no exception. Record `WORKTREE-MATCH: True` (rev-parse --show-toplevel equals the launch path, compared in-session) and `WORKTREE-LEAF: <last segment>`; the executor substitutes `<execution-worktree-root>` from its launch prompt.
6. **Footprint set equality must drop the feature folder.** The plan is in INHERITED (committed before plan start) yet modified by check-offs, and later artifacts are untracked and appear only in porcelain; "the two evaluated sets are equal" is false unless both have `docs/features/active/<feature>/` removed first.
7. **`_pester.yml` floors a union, not a folder.** Run.Path (line 41) and CodeCoverage.Path (line 45) list dependencies, hygiene and vscode together and line 71 applies one 80 percent floor to that union; do not write "measures scripts/dependencies at an 80 percent floor".
8. **Format-TrxRunSummary line shapes.** Line 2 is `Total N, executed N, passed N, failed N.` (assert "ends `, failed 0.`"), line 5 is `Failed tests: none` (TrxSummary.ps1 lines 140-147). "second line reads `failed 0.`" is not a line.
9. **`dotnet --list-sdks` is not a marker gate.** With `global.json` `paths` and `rollForward latestFeature` the row text is host-dependent; gate `dotnet --version` beginning `8.0.` plus `Test-Path <root>/.dotnet-sdk/sdk/8.0.205` (Install-RepoDotNetSdk.ps1 lines 3, 36, 56) and merely record the list.
10. **Mechanical CR-tolerance sweep.** After fixing one `$` anchor on a CRLF file, enumerate every `` $` `` pattern in the plan and classify each (command output, printed value, LF file, CRLF file); only the CRLF-file ones need `\r?$`. spec.md here is LF (CMD-CRCOUNT 0), so `^## Planner Amendments$` stands.
11. **Glob a leaf, not a folder.** `Glob lib/*` returns directory entries inconsistently; `Glob lib/*/*.dll` and "record the distinct parent folder names" is the observable.
12. **Clause (8)-style "equals its P0 value minus 1" needs the before-value named in the same task** (`REDIRECTS-BEFORE:`), or the gate reads a figure no artifact holds.
13. **Record an accepted amendment in the plan body.** When the orchestrator accepts a planner amendment, delete the "if rejected, the strict form applies" branch from the task; a now-false conditional reads as a live alternative to the executor.
