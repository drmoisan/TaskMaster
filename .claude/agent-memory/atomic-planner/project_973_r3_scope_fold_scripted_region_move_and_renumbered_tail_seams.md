Seams met while widening the issue #973 plan in place (revision 1.2 to 1.3, 2026-10-03) for a maintainer scope fold under the related-defect directive: Part F (six unused `using Microsoft.Graph.*` lines in five UtilitiesCS files), Part G (CLAUDE.md line 211 premise), Part H (CategoryClassifierGroup.cs 539 lines, split by partial class). Worktree `.claude/worktrees/agent-a24d410b914bcefd7`.

**Why:** each is a place where the obvious plan text would have been unsatisfiable or would have let the executor choose its own evidence.

**How to apply:** when a fold adds C# source edits to a plan that previously had none, or a file-size split by region move.

1. **Move a region by script, not by transcription.** A 93-line verbatim move through the Edit tool means the executor retypes 93 lines; the census then measures its typing. Use two `pwsh` payloads that locate the region by its `#region`/`#endregion` marker text (`[Array]::IndexOf` on `ReadAllLines`), copy the slice, and write CRLF with the source file's BOM state. Keep the verbatim proof computed, not transcribed: `Compare-Object -SyncWindow 0` of the marker-bounded slice from `git show <PLAN-START-HEAD>:<path>` against the new file, plus the diff's `-` lines (minus the using and declaration lines, blank ends trimmed) against the new file's class body.
2. **Remove the blank lines that precede the moved `#region`.** CSharpier strips blank lines before a closing brace, so leaving `\n\n    }` behind produces a formatter rewrite of the original and a diff that is no longer "only the declaration line changed". The cut starts at the first blank line above the marker; record `BLANK-LINES-REMOVED-BEFORE-REGION`.
3. **A fallback `git checkout <earlier sha> -- <csproj>` discards every later addition to that file.** The Part C fallback restored UtilitiesCS.csproj at commit A, which would also have dropped the Part H Compile Include committed later. Check out the other paths and edit the one element out of the shared file.
4. **Insert new check-offs between the pending-manual task and the status/commit tail.** Keeping P5-T18 (AC18 pending-manual) in place and adding P5-T19..P5-T23 moved only the status summary and commit C (to P5-T24/P5-T25); grep every `P5-T19|P5-T20` reference (D8, C4, C8, P3-T15 "committed by", the tasks' own text) and let the revision log say the older entries name the former IDs.
5. **Format-sensitive files entering the Write Set open a commit gap.** The original loop committed only the feature folder at the end; once CSharpier can rewrite a .cs file in Phase 4, a repair has nowhere to land and the P4-T11 porcelain gate fails. Add a conditional loop-fix commit to the loop rule (explicit pathspecs, D8 trailer form, recorded as `LOOP-FIX-COMMIT: <sha>|none`).
6. **Scoped format, repo-wide check, count = baseline + 1.** With a clean P0 `check .`, scope `csharpier format` to the six .cs paths, observe rewrites by `git hash-object` before/after (never `Formatted N`), then `check .` and gate `Checked N` at the P0 count plus the one new file.
7. **`\x60` is the backtick in a Grep-tool (ripgrep) pattern** (verified: `there is no \x60Directory\.Build\.props\x60` returned 1 on CLAUDE.md:211). Use it when the asserted token contains backticks, so the plan's inline code spans stay well formed.
8. **.NET file APIs in a pwsh payload ignore `Set-Location`.** `[IO.File]::ReadAllLines("relative")` resolves against the process directory, not the PowerShell location; build absolute paths with `Join-Path (Get-Location).Path`. Also pass `git -C $repo` inside payloads.
9. **New CMD-REBUILD keys for using deletions:** `USING_DIAG_LINES` (`CS0246|CS0103|CS0104|CS0234|CS1061`), `UTILITIESCS_CSC_LINES` (the echoed csc line's `/out:obj\Debug\UtilitiesCS.dll`, normal verbosity) and `NEWFILE_CSC_LINES` (the new file name on that csc line: 0 at baseline, >=1 after the Compile Include; a free negative control).
10. **A `private` member with no caller moves as is.** `Condition(object)` in the moved region has no caller; the spec forbade refactoring moved members, so the plan states the fact rather than "fixing" it and does not claim the helper is reached.
