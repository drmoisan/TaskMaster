**13. Revision round 3 seams (3 deltas, 2026-09-28).** (a) Line endings break hash anchors: `.gitattributes` is `* text=auto` and the session has `core.autocrlf=true`, so `git checkout` writes CRLF while a Write-tool file is LF; `git diff --exit-code HEAD` still exits 0 (normalized compare) but the SHA-256 differs. Fix pattern: in the fix-commit task, after the commit run `git ls-files --eol -- <write set>` (EOL-BEFORE), for each entry not `w/crlf` do `Remove-Item` then a separate `git checkout -- <path>` (a stat-clean file is NOT rewritten by checkout, so it must be deleted first), re-run `ls-files --eol` (EOL-AFTER), record EOL-RESTORED, and take every FIX-HASH anchor AFTER the restore; acceptance becomes "EOL-AFTER all `i/lf w/crlf`; unrestored .cs hashes equal the scoped-format hashes". (b) `.editorconfig` `[*.{cs,vb}]` (header 619) carries `end_of_line = crlf` (669) and there is no .csharpierrc; CSharpier documents reading that key, so the scoped `csharpier format` may already have converted new files (EOL-RESTORED: NONE) — keep the restore conditional and let the record decide; a CRLF file is the formatter's fixed point, so the repo-wide format does not rewrite it (still gate on REWRITTEN). (c) CORRECTED in round 4: `core.autocrlf` IS readable from inside a worktree — `git config --show-origin --get-all core.autocrlf` issued against the worktree reported `true` from the Git for Windows system configuration file (the earlier claim confused the common git dir, which holds only the repo-level config file, with the system/global scopes git always reads). Cite the command and its origin in the fact rather than "stated by the preflight", and still keep the `ls-files --eol` observation (EOL-BEFORE/EOL-AFTER) in the plan as the gate. (d) The runner's stale-output removal must include `coverage\test-results\mstest-coverage-run.summary.txt` (results dir + TRX base name + `.summary.txt`, runner 418-420) or SUMMARY_PRESENT is pre-satisfied. (f) Do not backtick `w/crlf`, `i/lf`, `w/` tokens: the blast-radius harvester reads any backticked slash-bearing token as a path.
