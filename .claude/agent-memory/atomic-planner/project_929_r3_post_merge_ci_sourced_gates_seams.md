Seams from applying the coordinator's revision-3 directives to plan 929 (worktree agent-a74dcedbc13b789fd, HEAD 3091b8af9 = merge of origin/main 231e1c0b5) on 2026-09-30, in a session with no Bash tool.

**CI never runs on a feature-branch push here.** `.github/workflows/ci.yml` triggers on push only for `main` and `development`, plus `pull_request` and `workflow_dispatch` (lines 3 to 8). A directive that says "read coverage from the CI run on the pushed head" therefore needs a dispatch step: `gh workflow run ci.yml --repo drmoisan/TaskMaster --ref <branch>` inside one pwsh payload, then re-run `gh run list --workflow ci.yml --branch <b> --json databaseId,headSha,status,conclusion,event,createdAt` filtered on `headSha -eq HEAD` until a run appears, select the greatest databaseId, block with `gh run watch <id> --interval 60` (gh's own poll; re-invoke on tool timeout, never Start-Sleep), then read the job with `gh run view --job <jobid> --log` (omit the run id: gh ignores it when `--job` is given) and download the one-file `pester-coverage` artifact. Also require `git ls-remote --heads origin <b>` to equal HEAD before dispatch. A PR-triggered run for the same head is reused when one exists.

**CSharpier and gitignored XML are unobserved.** `.csharpierignore` excludes `**/evidence/**`, `*.cobertura.xml`, `*.coverage`, `*.coveragexml`, `*.trx`, project files, `packages.config`, `app.config` and nothing under `artifacts/` or `coverage/`; `run_poshqc_test` writes two `*.xml` files under `artifacts/pester`, the coverage runner writes `coverage/coverage.cobertura.jacoco.xml` (not matched by `*.cobertura.xml`) and CI downloads add more. Repository "Checked N" deltas (927: 1623 to 1625, 931: 1623 to 1625) are each explained by two added .cs files, so they do not settle whether CSharpier honours .gitignore. Gate shape used: record `XML-CANDIDATES:` (sorted list of *.xml under artifacts/ and coverage/ excluding *.cobertura.xml) beside "Checked N" at baseline and final; accept `CHECKED-DELTA` equal to 0 or to `XML-DELTA`, record `CSHARPIER-COUNTS-IGNORED-XML:` true/false/undetermined, and cite the footprint's 0 *.cs paths as the independent check.

**New CI hygiene guard.** `_hygiene.yml` runs `scripts/hygiene/Test-RepositoryHygiene.ps1` over `git ls-files` (skipping the `.claude/` prefix): rule A classifies a tracked .xml by root element (report with class/sourcefile/method/line = jacoco-raw; report without = jacoco-projection; coverage = cobertura; TestRun = trx) and rule B flags any line matching a drive letter, colon, `users`, separator, identifier-start (placeholders beginning with `<` never match). It reads worktree bytes of tracked paths, so a local run before the final commit covers evidence committed earlier and Write Set files. Committed projection copies must carry no class/sourcefile/method/line element (assert `PROJECTION-RAW-ELEMENTS: 0` when copying).

**Merge-base after a mid-plan merge.** When the branch merges origin/main and the merge-base becomes the merged main tip (second parent), two-point `git diff <BASE-SHA> -- <path>` stays correct (none of main's commits lie between BASE-SHA and HEAD); the three-dot rewrite of #927 was needed only because that plan's BASE-SHA predated the merge. Record `git merge-base --is-ancestor <merged tip> HEAD` exit 0 at P0-T1 as proof the executor's worktree carries the merge.

**Intermediate red-by-design test runs.** Once the fail-before test file exists, every folder-wide run before the last fix is red: state per task the exact root `failures` count (4 while all tree tests are red, 1 after three fixes, 0 after the last) with `ExpectedExitCode: 1`, derive `EXIT_CODE` as 0 only when ok is true AND JUnit root failures is 0, and keep per-suite `tests=`/`failures=` from the JUnit suite lines. Root totals move 131 to 135 (new file) to 137 (two added Its).

**PoshQC JUnit shape (verified from the document).** Root `testsuites tests= errors= failures= disabled=` (no skipped at root); each `testsuite name=<absolute path> tests= failures= skipped=` with a `properties` block carrying framework-version, machine-name, user, cwd; each `testcase name=<Describe.Context.It> status= classname=<absolute path>`. Transcribe `Split-Path -Leaf` and testcase names only.

**No-shell session mechanics.** Read `.git/worktrees/<id>/HEAD`, `logs/HEAD` (last line = current operation), and loose refs under `.git/refs/` (packed-refs is stale once a loose ref exists). Glob returns nothing for paths under `.claude/worktrees/<id>/...` and hidden dirs; use Grep (`^` with count mode for line counts, `files_with_matches` for enumeration) and Read on explicit paths instead. Grep respects .gitignore, so gitignored files (artifacts/, coverage/) must be Read by explicit path.

**How to apply:** for any TaskMaster plan that sources a figure from CI on a feature branch, plan the dispatch and the polling; for any "Checked N equals baseline" gate, record the ignored-XML candidate list on both sides; run the hygiene guard locally before the last commit; and when a coordinator says a task is N/A, keep the ID and give it a read-only artifact (Timestamp, Command, EXIT_CODE, Output Summary) so no Phase 0 box is ticked without evidence.
