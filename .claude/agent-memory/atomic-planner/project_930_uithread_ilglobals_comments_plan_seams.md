**Why:** each item changed a task shape relative to the #839/#871 precedents this plan started from.

**How to apply:** any C# plan that runs the coverage runner, deletes a public static member, or tests `UiThread.SynchronizationContextAwaiter`.

1. **The coverage runner has changed shape since the #839/#871 memories.** `scripts/vscode/Invoke-MSTestWithCoverage.ps1` (440 lines, entry guard at 437) now: takes `-ResultsDirectory` (default `coverage\test-results`) and `-LogFileName` (default `mstest-coverage-run.trx`) on `Invoke-MSTestWithCoverageMain` (lines 283-284) but NOT on the script-level param block, so they are reachable only by dot-sourcing and calling Main; appends `/ResultsDirectory:` and `/Logger:trx;LogFileName=` to the inner vstest list (92-93); asserts BOTH the 80 percent line and the 75 percent branch floors on the post-processed first-party document (386-387; Threshold.ps1 52 and 122); prints `First-party coverage: lines A/B (P%), branches C/D (Q%)` (FirstParty.ps1 117-120); writes `<output-stem>.jacoco.xml` beside the Cobertura output (393-401) and `<trx-stem>.summary.txt` beside the trx (417-425) via `Invoke-MSTest.TrxSummary.ps1`; and discards the raw Cobertura unless its parent is exactly the repo coverage dir (427-431). Plans should COPY those two generated files into evidence rather than author projections. Pass `-ScriptRoot scripts/vscode` explicitly when calling Main after a dot-source so `$repoRoot` resolves to the worktree.
2. **Adding a test filter or `/Blame` to the runner without editing it:** dot-source, then redefine `Get-DotnetCoverageArgumentList` with the same seven parameters and the runner's own list plus the extra inner-vstest tokens; a later same-scope function definition wins. Wrap Main in try/catch because the dot-source sets `$ErrorActionPreference = 'Stop'`, so a threshold throw would otherwise end the pwsh before the trailing status lines print. Shell-icon classes to exclude on this host (verified present 2026-09-28): `ShellUtilities_Tests`, `ShellUtilitiesStatic_Tests`, `SysImageListHelperTests` (UtilitiesCS.Test.HelperClasses) and `OSBrowser_Tests` (UtilitiesCS.Test.EmailIntelligence); no `TestCategory` on any of them.
3. **Deleting a public static member that a test asserts by name:** do not replace the test with `GetField("Name")` absence checks, because the quoted name then survives the plan's own "no reference by string name" sweep. Assert the property instead: `GetFields(Public|Static)` all `IsInitOnly`, and the name set `BeEquivalentTo` the `nameof(...)` list of the survivors. Both fail on the unfixed tree and carry no quoted member-name token.
4. **`ILGlobals.cs` line 113 (`Cache`) is followed by a blank line 114 at the top of the class body**; delete both or CSharpier removes the blank and the diff shows two deletions whatever the executor did. `modules` at 131 sits between a field and a blank line, so a single-line deletion is stable.
5. **`new DispatcherSynchronizationContext()` calls `Dispatcher.CurrentDispatcher` and creates a dispatcher on the calling thread**, which defeats a "thread owns no dispatcher" repro. Use the `(Dispatcher)` overload with a `SharedStaDispatcherHost` (internal sealed, UiThreadInitContract_Tests.cs:135) owned by another thread, and evaluate on an `ApartmentThreadRunner.RunOnThread(ApartmentState.MTA, ...)` thread. `UiThread.cs` is 306 lines; the dispatcher exit is 197-201 and `_dispatcher is not null` occurs exactly once (184) before the fix.
6. **Tree facts re-derived 2026-09-28:** the two QuickFiler `.Search.cs` parts are 102 and 45 lines with the stale tokens at lines 11 and 10; `UiThreadApartmentMeasurement_Tests.cs` 164 lines with `[DoNotParallelize]` twice; `ILGlobals_Tests.cs` 270 lines, 14 tests, no attribute; `UtilitiesCS.Test.csproj` Compile items at 269 and 517. **Round 3 (preflight round 2 returned 12 mechanical defects, design confirmed; all applied 2026-09-28):**

17. **Bash-to-pwsh transport (measured by preflight):** a doubled quote inside a `$( )` subexpression of an expandable string fails to bind, and a doubled backslash arrives single at the native executable. Build such literals outside the string: `$q = [string][char]34; $csc = "Task " + $q + "Csc" + $q` and `$bs = [regex]::Escape([string][char]92)`, then pass by variable. Doubled quotes in plain expressions outside `$( )` (e.g. `SelectNodes("//*[local-name()=""UnitTestResult""]")`) are fine; hoist the call into a variable and put only `$var.Count` in the subexpression. A regex character class needing a backslash becomes `"[" + $bs + "/]"`.
18. **The runner's JaCoCo projection name keeps the Cobertura stem:** `930-STAGE.cobertura.xml` projects to `930-STAGE.cobertura.jacoco.xml` (GetFileNameWithoutExtension + .jacoco.xml, runner 393-395); the summary is `<trx-stem>.summary.txt` (417-420).
19. **Processed Cobertura `filename` attributes use native (backslash) separators** (runner comment at 377), so a per-file `-match "Dir/File[.]cs$"` predicate must `-replace $bs, "/"` first, and the task must gate `CLASS_NODES` and `LINES_VALID` at least 1 so a silent predicate miss is observable.

21. **Evidence-ownership sentence must name shared files explicitly** (an appended AC summary and a re-run Outlook probe are "owned by one task with stated exceptions", not "written by exactly one task").
22. **Porcelain scope gates must admit `PreExistingWorktreePaths:`** recorded at P0 (D8 said so; the task text did not).
23. **Commit literals carry the trailer angle-bracket-free** (`Co-Authored-By: Claude Opus 5.5 noreply@anthropic.com` inside the `-m` string) so the exempt-form hook's no-`<>` rule holds; a Claude-Session line goes in a separate `-m`.
24. **`$LASTEXITCODE` must be captured immediately after the `git grep` assignment**, before any later command overwrites it, when the task records the grep exit by name.
