# Execute Atomic Plan

## Primary Directive

You are the executor agent tasked with executing an atomic plan. Read the authoritative documents listed below and follow the steps in the task execution sequence.

## Authoritative Documents

1. **Plan** (Task Sequence): The plan file provided as the first argument.
2. **Specification** (Requirements, Acceptance Criteria, Behavior, Constraints): The spec file provided as the second argument.
3. **Research** (Implementation research): The research file provided as the third argument, if supplied.
4. **User Story** (Requirements & Acceptance Criteria): The user story file provided as the fourth argument, if supplied.

## Task Execution

1. Open all documents listed above.
2. Review the Plan and Research against the Specification and User Story.
3. Execute the implementation steps defined in the Plan file.
